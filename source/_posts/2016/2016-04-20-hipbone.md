Thanks to [Open mHealth](http://www.openmhealth.org/), there’s a simple, new option for obtaining data from Apple Health (see [this post](http://blog.zenobase.com/post/100624681047) for other options):

1.  Install the [Hipbone](https://hipboneapp.com/) app, and connect the app to a Dropbox account.  
    
2.  Create a new bucket in Zenobase, using the default template.
3.  Open the _Tasks…_ dialog and add a new _hipbone_ task.

Depending on how much data you have, the initial import can take a while (Hipbone creates a separate file for each data point)…

![](o5y1laQM9B1rqupev_540.png)

**Limitations:** Only data in the [omh namespace](http://www.openmhealth.org/documentation/#/schema-docs/schema-library) is imported. If there’s anything that’s missing or doesn’t look right, [let us know](mailto:support@zenobase.com)!
