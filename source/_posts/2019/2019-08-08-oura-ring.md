Zenobase now supports retrieving daily summary data, sleep stats, and readiness scores from [Oura](https://ouraring.com/).

![](1ad064c5692277ff2e41cb122906b4b9f98fff94.png)

To get started, simply create a new bucket using one of the “Oura” templates. **Tip:** To analyze data across multiple buckets, create a “view”.
